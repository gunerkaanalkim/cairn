# Contributing

PRs are welcome. Please ensure tests pass.

## Development Setup
Run `npm ci` to install dependencies.

## Verification
Run `npm run verify` before submitting any pull request. This ensures that the library builds, all tests pass, and the demo application builds successfully.

## Branch Naming
Use `feature/<name>` or `fix/<name>` for branches.

## Commit Messages
Use conventional commits (e.g., `feat: ...`, `fix: ...`).

## Code Style
Run `npm run format` (or configure your editor) to maintain consistent code formatting before committing.
